# Rangkuman Day-1-Bus_Simulator-Fathia_Azzahra_Putri
Repository (atau repo) adalah tempat terpusat untuk menyimpan semua file, kode, dokumen, dan sumber daya sebuah proyek. Ini seperti hub yang menjaga semuanya tetap teratur dan dapat diakses oleh orang lain/tim.
Repository mencatat setiap perubahan, seperti: siapa yang membuatnya, kapan dibuat, dan alasannya. Jika ada yang bermasalah atau perlu ditinjau, selalu dapat kembali ke versi sebelumnya. Membuat kolaborasi ddengan orang lain/tim menjadi lebih efisien.
Working directory adalah sebuah checkout tunggal dari satu versi milik proyek. Berkas-berkas ini ditarik dari basis data yang telah dimampatkan dalam direktori Git dan ditempatkan pada diska untuk Anda gunakan atau sunting.
Staging area adalah sebuah berkas, umumnya berada pada direktori Git Anda, yang menyimpan informasi tentang apa yang akan menjadi commit Anda selanjutnya. Terkadang disebut juga sebagai index, namun juga sering disebut sebagai staging area
