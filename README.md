# Day-1-Bus_Simulator-Fathia_Azzahra_Putri
Repository (atau repo) adalah tempat terpusat untuk menyimpan semua file, kode, dokumen, dan sumber daya sebuah proyek. Ini seperti hub yang menjaga semuanya tetap teratur dan dapat diakses oleh orang lain/tim.
Yang membuat repository bermanfaat adalah dukungannya terhadap version control. Artinya setiap perubahan dicatat: siapa yang membuatnya, kapan dibuat, dan alasannya. Jika ada yang bermasalah atau perlu ditinjau, selalu dapat kembali ke versi sebelumnya.
Belajar mengenai repository, membuat git sendiri, prompting AI, cara menggunakan Git secara manual atau melalui Github
